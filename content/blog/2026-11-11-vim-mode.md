# Vim mode

You can now move around the site with `h` `j` `k` `l`, jump with `gg` and
`G`, and type commands after `:`, like in vim.

Before this, the only way to get around the site with a keyboard was Tab,
one link at a time, in page order. On the home page, getting to a cat a few
rows down meant tabbing through every cat before it, and there was no way to
go left, right, up or down. So I added the keys a lot of us already have in
our fingers.

## Moving around

- `h` `j` `k` `l` move the highlight left, down, up and right, to the
  nearest link or button in that direction. Enter opens it.
- `gg` (two `g` presses in quick succession) goes to the top of the page,
  and `G` (Shift+G) to the bottom.

The movement follows what the page looks like on your screen. On the home
page, `j` goes from the logo to the copy button to the first cat, and from
there to the cat below it, whether the grid has three columns, two or one.
The highlight is the browser's own keyboard focus, so Tab and Shift+Tab
carry on from wherever you left it, and screen readers follow it too.

## The command line

<img src="/blog/vim-mode/command-line.webp" width="1056" height="644" alt="The command line open over the home page, empty, listing every command: status {code}, blog, lang {eng|cat}, theme {dark|light} and vim {on|off}, each with a short description.">

Press `:` and a command line opens over the page. Start typing and it lists
the commands that match. Tab completes the selected one, ↑ and ↓ (or Ctrl+P
and Ctrl+N) move through the list, and Enter runs it:

- `:status 404` opens the [404 page](/status/404). `:status 4` lists every
  4xx status, so it's also a quick way to look one up.
- `:blog` goes to the [blog](/blog).
- `:lang cat` and `:lang eng` switch the page to Catalan or English.
- `:theme dark` and `:theme light` switch the theme.
- `:vim off` turns the vim keys off, `:` included.

Esc closes it. Get a command wrong and you get vim's own error messages,
`E492: Not an editor command` included.

## Settings

<img src="/blog/vim-mode/settings.webp" width="1056" height="644" alt="The settings window open over the home page, with the Vim mode and Dark theme switches both on, and a Close button.">

There's a new Settings link in the footer, next to the Blog link. It has
two switches:

- **Vim mode**, on by default. Single-letter shortcuts can be triggered by
  accident, especially by people who use speech input to control their
  computer, so there has to be a way to turn them off. Once they're off,
  this switch is also how you turn them back on.
- **Dark theme**. The site has followed your system's light or dark setting
  for a while, and now you can choose. Set it to the opposite of your system
  and it sticks; set it back to match your system and the site goes back to
  following it.

Both are remembered across pages and visits.

## Vim extensions

If you use a browser extension like Vimium, Tridactyl or Surfingkeys, it
gets `h` `j` `k` `l` before the site does. To use the site's keys instead,
add http.cat to the extension's exclusion list.

As always, [let me know](https://github.com/httpcats/http.cat/issues) if
something doesn't work the way you'd expect. `:wq`
