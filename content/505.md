## Description

The HTTP `505 HTTP Version Not Supported` server error response status code indicates that the server does not support, or refuses to support, the major version of HTTP that was used in the request message. The server is unable or unwilling to complete the request using the same major version as the client.

The response should contain a representation describing why the version is not supported and which other protocol versions the server does support.

<aside class="info"><strong>Note:</strong> This error is rare in practice, since most servers accept several HTTP versions. It can show up when a very old client speaks HTTP/0.9 or HTTP/1.0 to a server that has dropped them, or when a client sends an HTTP/2 or HTTP/3 request to a server that is not configured for it.</aside>
