## Descripció

El codi d'estat d'error del servidor HTTP `505 HTTP Version Not Supported` (Versió HTTP no compatible) indica que la versió d'HTTP utilitzada en la sol·licitud no és compatible amb el servidor.

És habitual trobar aquest error quan una línia de sol·licitud està formada incorrectament, com ara `GET /path to resource HTTP/1.1`, o quan s'utilitza `\n` per finalitzar la línia de sol·licitud en lloc de `\r\n`.

Per exemple, els sistemes intermediaris, com ara els equilibradors de càrrega (*load balancers*), poden no gestionar correctament les línies de sol·licitud d'una petició reenviada, tal com s'il·lustra en l'exemple següent.
